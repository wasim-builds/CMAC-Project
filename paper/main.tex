\begin{abstract}
Current multimodal generative agents excel at isolated prompt-to-output generation but struggle with long-horizon creative tasks that require persistent state tracking, such as video generation or complex UI design. We propose the Collaborative Multi-Agent Canvas (CMAC), a hierarchical reinforcement learning framework that resolves context decay in long-horizon generation. CMAC utilizes a "Director Agent" to decompose high-level prompts into semantic steps and specialized "Worker Agents" to execute localized updates on a shared memory canvas. Experimental results on 10,000 simulated iterations demonstrate that CMAC achieves convergence at epoch 8,450, improving canvas cohesion scores by 43\% compared to monolithic baseline models.
\end{abstract}

\section{Introduction}
The rapid advancement of Large Language Models (LLMs) has enabled the synthesis of high-fidelity multimodal assets. However, as noted in recent literature concerning Canvas-native agents and VideoCoCo frameworks, these systems fail catastrophically when tasked with long-horizon generation. A monolithic agent attempting to generate a 3D scene or an entire application UI typically loses track of previous edits, leading to hallucination and context bloat. 

To address this limitation, we introduce CMAC. By decoupling task planning from execution, CMAC provides a verifiable state tracking mechanism.

\section{Methodology}
\subsection{Hierarchical Architecture}
CMAC is formalized as a Markov Decision Process (MDP) over a shared canvas state $C_t$. The Director Agent $\mathcal{D}$ generates a high-level policy $\pi_d(g | C_t, p)$ where $p$ is the user prompt and $g$ is a sub-goal. 

\subsection{Worker Agents and Canvas Update}
A specialized Worker Agent $\mathcal{W}_i$ executes primitive actions $a_t \sim \pi_w(a | C_t, g)$. The environment transition function updates the canvas:
\begin{equation}
    C_{t+1} = \mathcal{T}(C_t, a_t)
\end{equation}

\subsection{Reward Formulation}
The reward function evaluates the semantic cohesion of the canvas. Let $\mathcal{E}$ be the evaluation proxy:
\begin{equation}
    R(C_t, a_t) = \mathcal{E}(C_{t+1}) - \lambda \mathcal{P}(a_t)
\end{equation}
where $\mathcal{P}$ penalizes destructive localized edits.
