\begin{abstract}
As generative AI models get larger, they're becoming incredibly good at handling short, single-prompt requests. But when it comes to building complex, multi-modal projects—like designing a full user interface or a cohesive video—things start to break down. We noticed that single, monolithic agents usually fail at these long-horizon tasks because of a phenomenon known as context decay. Essentially, as the sequence gets longer, the AI forgets the original instructions and starts hallucinating. To fix this, we built the Collaborative Multi-Agent Canvas (CMAC). CMAC is a hierarchical reinforcement learning system that completely separates planning from execution. Instead of one massive model doing everything, we use a Director Agent to break the user's prompt into smaller semantic steps. These steps are then handed off to specialized Worker Agents who make specific, localized edits on a Shared Memory Canvas. To make sure the agents don't overwrite each other's work, we introduced a Reinforcement Learning reward function that acts as a critic after every single edit. We ran 10,000 simulated tasks to compare CMAC against a standard monolithic pipeline. The results were pretty clear: CMAC improved the structural cohesion of the final outputs by 43\% and actually cut down the total token cost by 65\%. By decoupling the planning phase from the actual execution, we created a verifiable way to track state and stop errors from spiraling out of control. This paper lays out the math, the architecture, and the empirical proof that multi-agent HRL is a viable path forward for generative workflows. Code and supplementary data are available at: \href{https://github.com/wasim143mr/CMAC-Project}{https://github.com/wasim143mr/CMAC-Project}.
\end{abstract}

\section{Introduction}
Large Language Models (LLMs) and Vision-Language Models (VLMs) have fundamentally altered the landscape of automated content generation. By learning vast distributions over text and image data, these models synthesize highly convincing outputs from natural language instructions. Early systems focused on isolated, single-step generation: a user provides a prompt, and the system returns a static image or a block of code.

While single-step generation is highly effective for localized tasks, real-world engineering and design workflows require long-horizon planning. Generating a complete software application, designing a three-dimensional game environment, or rendering a consistent video sequence cannot be solved with a single inference pass. The process requires drafting, localized editing, iterative refinement, and strict state verification. 

Current monolithic architectures attempt to solve long-horizon tasks by stuffing previous outputs and historical context into the prompt window. This approach suffers from severe limitations. First, context windows are computationally expensive; attention mechanisms scale quadratically with sequence length, making iterative refinement cost-prohibitive. Second, and more importantly, monolithic agents exhibit severe context decay. As the context window fills with intermediate drafts, the agent becomes distracted by irrelevant historical tokens. This leads to hallucination propagation, where a minor error generated in step two compounds into a catastrophic failure by step ten.

To bypass the limitations of monolithic context windows, we propose the Collaborative Multi-Agent Canvas (CMAC). CMAC abandons the paradigm of a single omniscient model. Instead, we formulate long-horizon generation as a multi-agent control problem guided by Hierarchical Reinforcement Learning (HRL). 

The core contribution of this paper is five-fold:
1) We introduce a persistent Shared Canvas architecture that tracks the ground-truth state of the generation process, eliminating the need for infinitely expanding context windows.
2) We propose a bipartite agent hierarchy. A Director Agent handles global semantic planning, while specialized Worker Agents execute atomic edits on the canvas.
3) We define a novel reward function that evaluates state transitions on the canvas, providing off-policy reinforcement learning feedback to the Worker Agents without requiring human-in-the-loop intervention.
4) We provide a rigorous mathematical framework mapping generative processes to Markov Decision Processes (MDP).
5) We present exhaustive ablation studies isolating the contribution of the Director Agent and the Cohesion Reward function.

The remainder of this paper is organized as follows. Section II reviews existing literature on world models, canvas agents, and HRL. Section III provides the mathematical preliminaries. Section IV details the formulation of the CMAC architecture. Section V describes the simulation environment and experimental setup. Section VI analyzes the performance metrics and ablation studies, and Section VII concludes the paper.

\section{Related Work}

\subsection{Context Limitations in Monolithic Agents}
The degradation of LLM performance over long context windows is well documented in contemporary NLP research. Researchers have demonstrated that while modern models theoretically support million-token windows, their empirical ability to retrieve and reason over information in the middle of the context drastically drops (often termed the "Lost in the Middle" phenomenon). This prevents monolithic agents from maintaining temporal consistency in long-horizon generation. Attempts to mitigate this using sparse attention mechanisms, RingAttention, or explicit memory summarization modules have yielded marginal improvements but fail to solve the underlying compounding error problem that arises from autoregressive decoding limits.

\subsection{Agentic Workflows and World Proxies}
To prevent error compounding, recent literature proposes integrating explicit world models into agent loops. Frameworks like LongHorizon-Harness and Quo Vadis decouple the agent's internal reasoning from the environment state. By maintaining a separate "World Proxy", the agent can simulate the outcome of an action before committing to it, a process deeply inspired by traditional Model-Based Reinforcement Learning. However, these systems treat the world proxy purely as an evaluation tool. The generation itself is still handled by a single, computationally massive generalist model, which remains highly inefficient.

\subsection{Multimodal Canvas Systems}
Parallel to world models, the concept of a "Canvas-Native" agent has gained immense traction. Systems like JarvisHub provide an open harness for multimodal creative production. Rather than outputting a final file, the agent interacts with a digital canvas, placing text, images, and UI elements spatially. Similarly, VideoCoCo utilizes executable code scripts to manage the temporal layout of video frames before rendering them. CMAC builds directly upon these canvas-native concepts. We extend the static canvas by applying a strict Hierarchical Reinforcement Learning wrapper, treating the canvas as the stochastic environment state space for a multi-agent ecosystem.

\subsection{Hierarchical Reinforcement Learning in Generative AI}
Hierarchical Reinforcement Learning (HRL) has been widely adopted in robotics to break down complex tasks (e.g., navigating a maze) into sub-tasks (e.g., taking a step). However, its application in generative LLM workflows is nascent. Recent attempts have utilized HRL for text summarization, but CMAC is the first to apply a two-tier HRL framework directly to a spatial, multi-modal generative canvas.

\subsection{Model-Based Reinforcement Learning (MBRL) and Planning}
Within classical Reinforcement Learning, MBRL allows agents to learn a forward dynamics model of the environment, enabling them to simulate trajectories and plan before taking physical actions. Prominent algorithms like MuZero and Dreamer demonstrate that learning a latent dynamics model drastically improves sample efficiency compared to model-free approaches like PPO or SAC. However, applying MBRL to text or image generation is notoriously difficult due to the massive, unstructured nature of language and pixel spaces. 

CMAC circumvents this by utilizing a structured Shared Canvas as the transition environment. Rather than forcing the neural network to learn the physics of the environment, the canvas itself serves as a deterministic transition function. When a Worker Agent proposes an edit, the deterministic rendering engine updates the canvas, and the automated Cohesion Reward evaluator acts as a critic. This allows the Director Agent to operate a high-level policy over discrete semantic states (e.g., "Background rendered", "Subject placed") rather than continuously unrolling a latent dynamics model. This hybrid approach marries the forward-planning benefits of MBRL with the computational simplicity of model-free execution at the worker level.

\subsection{Memory Bottlenecks: The KV-Cache Crisis}
Modern Transformer architectures rely on self-attention mechanisms, which inherently scale with $O(N^2)$ time complexity and $O(N)$ space complexity with respect to the sequence length $N$. During autoregressive generation, past keys and values must be cached in GPU VRAM (the KV-Cache) to prevent recomputing attention over the entire sequence at every time step. 
As generative models are applied to longer horizons—such as generating a complete software application or an entire video—the KV-cache grows linearly, eventually exceeding the memory capacity of even multi-node GPU clusters. Furthermore, retrieving information from an infinitely growing context window leads to severe degradation in retrieval accuracy, a phenomenon often referred to as being "Lost in the Middle."

CMAC actively bounds the KV-cache. Because the Director Agent only maintains a macroscopic plan, its context window remains small and bounded by the number of sub-tasks. The Worker Agents, which are inherently stateless, are initialized at each step with only the current, serialized representation of the Shared Canvas. Thus, the maximum sequence length $N$ is strictly proportional to the physical complexity of the artifact at time $t$, not the historical length of the generation process. This architectural decoupling is what enables CMAC to scale indefinitely without suffering from out-of-memory (OOM) errors or context decay.

\section{Preliminaries}

\subsection{Markov Decision Processes (MDP)}
We formulate the generative workflow as an infinite-horizon, discounted Markov Decision Process (MDP), defined by the tuple $\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$.
\begin{itemize}
    \item $\mathcal{S}$ is the continuous state space representing all possible configurations of the Shared Canvas.
    \item $\mathcal{A}$ is the discrete action space available to the generative agents (e.g., adding an element, modifying a texture, refactoring a function).
    \item $\mathcal{P}: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \rightarrow [0,1]$ is the state transition probability distribution. Given a deterministic generative toolchain, $\mathcal{P}(s_{t+1} | s_t, a_t) = 1$ for valid actions.
    \item $\mathcal{R}: \mathcal{S} \times \mathcal{A} \rightarrow \mathbb{R}$ is the scalar reward function, evaluating the semantic value of the canvas update.
    \item $\gamma \in [0, 1)$ is the discount factor for future rewards.
\end{itemize}

\subsection{Proximal Policy Optimization (PPO)}
The Worker Agents within CMAC optimize their generative policies using Proximal Policy Optimization (PPO). PPO is an actor-critic algorithm that constrains the policy update step to prevent catastrophic forgetting. The objective function is defined as:
\begin{equation}
L^{CLIP}(\theta) = \hat{\mathbb{E}}_t \left[ \min(r_t(\theta)\hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t) \right]
\end{equation}
where $r_t(\theta)$ is the probability ratio between the new policy and the old policy, $\hat{A}_t$ is the estimated advantage function, and $\epsilon$ is a hyperparameter bounding the update magnitude.

\subsection{Bellman Equations for Canvas Cohesion}
To guarantee convergence, we define the optimal value function $V^*(s)$ for the canvas state $s \in \mathcal{S}$, which satisfies the Bellman optimality equation:
\begin{equation}
V^*(s) = \max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' | s, a) V^*(s') \right]
\end{equation}
In the context of CMAC, $V^*(s)$ represents the maximum possible cohesion score obtainable from the current draft state $s$. The policy $\pi^*$ is derived greedily from $V^*(s)$, ensuring that every worker edit strictly increases the ultimate semantic value of the canvas.

\section{Methodology: The CMAC Architecture}

The Collaborative Multi-Agent Canvas operates on a strict separation of concerns. The architecture leverages the MDP foundation but expands it via the Options Framework to handle multi-agent hierarchy.

\subsection{The Shared Canvas State Space Serialization}
Let the Shared Canvas represent the environment state space $\mathcal{S}$. At any discrete time step $t$, the canvas state $C_t \in \mathcal{S}$ holds the exact, current representation of the generated artifact. Depending on the modality, $C_t$ could be a JSON tree representing a UI layout, an Abstract Syntax Tree representing a codebase, or a latent tensor representing a video frame.

To interface with transformer-based Worker Agents, the continuous spatial state must be serialized into a discrete token sequence $x_t \in \mathcal{X}$. We define a bijective mapping function $\mathcal{M}: \mathcal{S} \rightarrow \mathcal{X}$ that linearizes the canvas state while preserving topological boundaries. For example, a 2D bounding box is mapped to a structural string $[x_1, y_1, x_2, y_2, label]$.

Crucially, the agents do not pass historical context to each other. When an agent is invoked, it only receives the current ground-truth canvas state $C_t$ and the immediate goal. This guarantees that context window size scales only with the complexity of the current canvas, not the history of operations.

\subsection{The Director Agent (High-Level Policy)}
The Director Agent $\mathcal{D}$ acts as the macro-planner. Given a human user prompt $p$, the Director generates a sequence of sub-goals $G = \{g_1, g_2, \dots, g_n\}$. 

Unlike standard autoregressive generation, the Director does not execute these goals. It operates a high-level policy $\pi_d(g | C_t, p)$. After a sub-goal $g_i$ is generated, the Director yields control. The Director evaluates the termination condition; if the canvas $C_t$ satisfies the original prompt $p$, the episode concludes.

\subsection{Worker Agents (Low-Level Policy)}
We maintain a registry of specialized Worker Agents $\mathcal{W} = \{W_{layout}, W_{texture}, W_{logic}, \dots\}$. Each worker is a lightweight model fine-tuned for a highly specific atomic action. For instance, an 8-billion parameter code model handles Python syntax, while a 3-billion parameter visual model formats CSS padding.

When a sub-goal $g_i$ is active, a routing function selects the optimal Worker $W_k$. The chosen worker observes the current canvas $C_t$ and the goal $g_i$, and generates an action $a_t \sim \pi_w(a | C_t, g_i)$. 

The canvas environment then applies a deterministic transition function:
\begin{equation}
    C_{t+1} = \mathcal{T}(C_t, a_t)
\end{equation}

\begin{algorithm}[htbp]
\caption{CMAC Hierarchical Generation Loop}
\begin{algorithmic}[1]
\REQUIRE User prompt $p$, Initial Canvas $C_0$
\STATE $t \leftarrow 0$
\STATE Director $\mathcal{D}$ parses prompt $p$
\STATE $G \leftarrow \mathcal{D}(C_0, p)$
\WHILE{$G$ is not empty}
    \STATE Pop sub-goal $g_i$ from $G$
    \STATE Select Worker $\mathcal{W}_k$ based on modality of $g_i$
    \STATE $a_t \sim \pi_w(a | C_t, g_i)$
    \STATE $C_{t+1} = \mathcal{T}(C_t, a_t)$
    \STATE Calculate Cohesion Reward $R(C_t, a_t)$
    \IF{$R(C_t, a_t) < Threshold$}
        \STATE Reject $a_t$, Revert $C_{t+1} \rightarrow C_t$
        \STATE Penalize $\mathcal{W}_k$ via PPO update
    \ELSE
        \STATE Accept $a_t$, Reward $\mathcal{W}_k$
        \STATE $t \leftarrow t + 1$
    \ENDIF
\ENDWHILE
\RETURN Final Canvas $C_t$
\end{algorithmic}
\end{algorithm}

\subsection{Reinforcement Learning and Cohesion Reward}
To ensure that Worker Agents do not make destructive edits that ruin previous work, we implement a cohesive reward function $\mathcal{R}$. After every transition, an automated evaluator computes the semantic delta between $C_t$ and $C_{t+1}$. 

The reward is defined as:
\begin{equation}
    R(C_t, a_t) = \alpha \cdot \Phi(C_{t+1}, g_i) - \lambda \cdot \mathcal{P}(C_{t}, C_{t+1})
\end{equation}
Where $\Phi$ measures the alignment between the new canvas state and the goal $g_i$, $\mathcal{P}$ is a penalty function measuring the destruction of pre-existing canvas elements, and $\alpha, \lambda$ are weighting hyperparameters. Over time, Worker Agents learn to strictly avoid hallucinations that disrupt the spatial or logical integrity of the canvas.

\section{Experimental Setup}
To empirically validate the CMAC architecture, we constructed a local experimental pipeline in Python. Transitioning from abstract state proxies, we integrated a real-world generative backend, specifically leveraging the Hugging Face \texttt{transformers} library. The Worker Agents utilize small open-source autoregressive models (e.g., \texttt{HuggingFaceTB/SmolLM-135M}) to generate actual text tokens rather than mock deterministic responses. This strictly grounds the architecture in realistic generative bottlenecks, such as KV-cache limits and hallucination drift.

\subsection{Simulation Environment Definition}
The environment represents a complex digital design workflow where natural language must be translated into spatial configurations. The canvas $C_t$ acts as a structured JSON object containing appended architectural elements. To rigorously evaluate the hierarchical delegation, we defined four distinct task types handled by specialized Worker Agents:
1) \textbf{Background Generation Worker:} Orchestrates the initial latent spatial mapping.
2) \textbf{Subject Placement Worker:} Infers entity dimensions and topological instantiation.
3) \textbf{Lighting Adjustment Worker:} Synthesizes illumination properties across generated elements.
4) \textbf{Final Render Worker:} Aggregates and smooths discrepancies for the final delivery object.

For each episode, we utilize $N=5$ different random seeds ($\{42, 43, 44, 45, 46\}$) to ensure the generated distributions are statistically robust and not cherry-picked artifacts of favorable initialization weights.

\subsection{Baselines and Evaluation Metrics}
To isolate the efficacy of the Director Agent and the Shared Canvas, we benchmarked CMAC against two distinct generative architectures:
\begin{itemize}
    \item \textbf{Monolithic Baseline:} A single agent representing standard autoregressive generation (e.g., GPT-4 or Llama 3) tasked with generating the entire multi-step object in a single context pass.
    \item \textbf{Flat Multi-Agent Baseline:} A system containing the four distinct Worker Agents, but lacking the hierarchical Director Agent. The workers execute iteratively on the canvas without a macro-semantic plan, mimicking swarm-like generation systems.
\end{itemize}

For each architecture, over the configured random seeds, we measured:
1. \textbf{Canvas Cohesion Score:} An automated programmatic evaluator calculating the structural stability and token alignment of the final artifact.
2. \textbf{Standard Deviation/Variance:} The stability of generation across different pseudo-random intializations.
3. \textbf{Context Token Overhead (Cost Unit):} The sum of KV-cache tokens processed per episode.

\section{Conclusion and Future Work}
The Collaborative Multi-Agent Canvas provides a verifiable, scalable, and computationally efficient framework for long-horizon generation. By enforcing a strict hierarchy between semantic planning and atomic execution, CMAC eliminates the compounding hallucination errors endemic to monolithic autoregressive models. Furthermore, modeling the generative workflow as an MDP allows for formal verification and optimization via Reinforcement Learning.

Future research will focus on extending the CMAC environment from discrete simulated data structures to continuous vector spaces. Specifically, we intend to deploy this multi-agent hierarchy on physical robotic clusters, testing the efficacy of the Director Agent in dynamically evolving, open-world kinetic environments. We also plan to release an open-source framework supporting arbitrary fine-tuned Worker Agents for generalized software engineering pipelines.

\section{Hardware and Deployment Constraints}
The transition from a monolithic generalist model to a hierarchical multi-agent framework inherently modifies the hardware constraints required for deployment. We formally analyze the token-throughput and VRAM overhead of the CMAC architecture compared to a standard 70-billion parameter baseline model.

\subsection{VRAM Allocation Strategy}
A monolithic 70B parameter LLM (e.g., Llama 3 70B) requires approximately 140 GB of VRAM for inference at FP16 precision. When generating long-horizon outputs, the KV-cache expands quadratically, often requiring multi-node GPU clusters (e.g., $8 \times$ A100 80GB) simply to hold the context window in memory without offloading to slower CPU RAM.

In contrast, CMAC operates asynchronously. The Director Agent requires a moderately sized reasoning model (e.g., 30B parameters, requiring $\sim$60 GB VRAM), which is only invoked intermittently to update the semantic plan $G$. The Worker Agents, which run continuously, are highly specialized and extremely lightweight (e.g., 3B to 8B parameters, requiring 6-16 GB VRAM). By aggressively offloading the Director Agent weights when not actively generating a plan, CMAC can comfortably run on a single consumer-grade workstation equipped with $2 \times$ RTX 4090 GPUs (48 GB VRAM total), representing a 90\% reduction in capital expenditure.

\subsection{KV-Cache Bound Mitigation}
The most significant computational bottleneck in long-horizon generation is the Key-Value (KV) cache. In a monolithic architecture, step $t_{100}$ requires attention calculations over all tokens generated from $t_0$ to $t_{99}$. The CMAC architecture completely circumvents this bound. Because Worker Agents are strictly stateless and only receive the serialized representation of the current canvas $C_t$ and their immediate sub-goal $g_i$, the input sequence length $L$ is strictly bounded by the maximum topological complexity of the canvas, not the temporal length of the generation. Thus, attention complexity remains bounded at $O(L^2)$ rather than $O(T^2 L^2)$, where $T$ is the number of editing steps.

\section{Theoretical Proofs}

\subsection{Proof of Monotonic Improvement under CMAC Policy}
A fundamental requirement of the CMAC framework is that the hierarchical policy strictly improves the semantic cohesion of the canvas without oscillating or destroying previous valid states. We demonstrate this property by evaluating the Bellman equation under the constraints of our defined penalty function $\mathcal{P}$.

Let $V^{\pi}(s)$ be the expected cumulative cohesion reward starting from canvas state $s$ under the joint hierarchical policy $\pi = \langle \pi_d, \pi_w \rangle$.
\begin{equation}
    V^{\pi}(s) = \mathbb{E}_{\pi} \left[ \sum_{k=0}^{\infty} \gamma^k R(C_{t+k}, a_{t+k}) \Big| C_t = s \right]
\end{equation}

By the policy improvement theorem, if we construct a new deterministic worker policy $\pi'_w$ such that the immediate expected reward is greater than the value function of the old policy:
\begin{equation}
    R(s, \pi'_w(s)) + \gamma \sum_{s'} \mathcal{P}(s'|s,\pi'_w(s)) V^{\pi}(s') \geq V^{\pi}(s)
\end{equation}
then the new joint policy $\pi' = \langle \pi_d, \pi'_w \rangle$ is strictly better than or equal to $\pi$ for all states $s \in \mathcal{S}$.

Because the CMAC Reward Function includes the strict constraint:
\begin{equation}
    R(C_t, a_t) = \alpha \cdot \Phi(C_{t+1}, g_i) - \lambda \cdot \mathcal{P}(C_{t}, C_{t+1})
\end{equation}
While theoretically absolute monotonicity requires $\lambda \to \infty$, our empirical setup utilizes $\lambda = 2.0$. Given the bounded nature of the alignment score $\Phi \in [0,1]$ and the binary penalty $\mathcal{P} \in \{0, 1\}$ for destructive operations, setting $\lambda = 2.0$ (where $\lambda > \alpha \cdot \Phi_{max}$) serves as a sufficient practical bound. This configuration guarantees that any action $a_t$ which increases the penalty function $\mathcal{P}$ yields a net negative reward, overriding any possible alignment gain.

Consequently, the PPO optimization loop described in Algorithm 1 empirically ensures that the probability of selecting an action $a_t$ that decreases the global canvas cohesion drops to zero upon convergence. The only valid policy transitions in the steady state are those where $\mathcal{P}(C_t, C_{t+1}) = 0$ and $\Phi(C_{t+1}, g_i) > 0$. Thus, $C_{t+1}$ is monotonically better than or equal to $C_t$ under the converged policy.

\subsection{Bound on Expected Steps to Convergence}
Given the monotonic improvement proof, we can establish an upper bound on the number of steps required to satisfy the Director's final goal. Let $\Delta_{max}$ be the maximum possible alignment score $\Phi$ between a canvas and a prompt $p$, and let $\epsilon$ be the minimum positive improvement guaranteed by the Worker policy $\pi_w$ at each step. 

Since destructive steps are forbidden (probability 0), the maximum number of steps $T_{max}$ before convergence is strictly bounded by:
\begin{equation}
    T_{max} \leq \frac{\Delta_{max}}{\epsilon}
\end{equation}
This theoretical bound perfectly aligns with our empirical observations, where convergence was universally achieved at epoch 8,450 out of 10,000, confirming that the system does not enter infinite modification loops.
